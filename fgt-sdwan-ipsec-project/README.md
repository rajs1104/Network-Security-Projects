
FortiGate SD-WAN + Dual WAN + IPsec VPN (EVE-NG)

## Overview
This project simulates a branch office deployment using a single FortiGate firewall with:
- Dual WAN connections
- SD-WAN failover
- IPsec VPN tunnel to HQ
- LAN network with NAT and security policies


## Customer Problem Summary
A branch office was experiencing unreliable connectivity due to two low‑cost ISP links.  
They also needed secure connectivity to HQ for internal applications.  
Users reported outages, unstable access, and no automatic failover.

## Solution Summary
A FortiGate firewall was deployed with:
- Dual WAN links
- SD‑WAN for intelligent failover
- IPsec VPN tunnel to HQ
- CSR1000V routers simulating ISP and HQ environments

This provided stable internet, automatic failover, and secure HQ connectivity.
